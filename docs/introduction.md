# Reliability Simulation Documentation

## Introduction

For this project, the main focus was simulating the reliability/availability of different system configs via MATLAB, which included hardware failures and how redundancy can affect a system's ability to remain operational over a period of time. Throughout this documentation, we explained each simulation with its corresponding MATLAB code, and discuss the results to compare the different configs.

## Prerequisites

To run the simulations in this project, you will need access to MATLAB.

- **MATLAB Online:** [https://matlab.mathworks.com/](https://matlab.mathworks.com/)
- **GNU Octave:** [https://octave.org/](https://octave.org/)

The simulations were developed using MATLAB Online, but they could run using GNU Octave, which is a free, open-source alternative to MATLAB. Note: There may be some adjustments as we did not test it on there.

## Setup

We created a folder called `csc456-project` through MATLAB Online.
